Política de privacidad

Garmin FITNESS Sync es una aplicación de uso personal administrada por el propietario de la cuenta de GitHub gonzaloggarrido-dot. No admite cuentas de terceros.

Datos y finalidad

La aplicación consulta datos de actividades, resúmenes diarios y sueño de la cuenta Garmin autorizada. Lee metadatos y contenido de los archivos de Google Drive seleccionados para la aplicación y actualiza esos archivos con datos de Garmin. Estos datos se utilizan para el seguimiento personal de actividad y bienestar.

Acceso y almacenamiento

El acceso a Drive utiliza OAuth con el permiso drive.file. Los archivos permanecen en el Drive del usuario. Las credenciales de ejecución se almacenan en GitHub Actions Secrets y los procesos se ejecutan en un repositorio privado. Durante la configuración se conservan autorizaciones y copias de seguridad en el ordenador del usuario. Los registros de la aplicación omiten las credenciales y el contenido de salud.

Servicios y uso de los datos

Garmin, Google y GitHub intervienen en la obtención, almacenamiento o procesamiento necesario para la sincronización. La aplicación no vende datos, no los utiliza para publicidad y no los envía por sí misma a servicios de inteligencia artificial. Si el usuario decide consultar sus archivos mediante otro servicio, se aplicarán también las condiciones y permisos de ese servicio.

Conservación y control

El usuario puede detener GitHub Actions, revocar el acceso desde su cuenta de Google, revocar la clave de Garmin y borrar los secretos, archivos y copias locales. Detener la sincronización no elimina automáticamente los archivos o el historial conservados.

El uso de información recibida de las API de Google se ajustará a la Google API Services User Data Policy, incluidos sus requisitos de uso limitado.
