Garmin FITNESS Sync

Aplicación personal que copia datos de actividad y bienestar de Garmin Connect a archivos JSON privados de Google Drive para facilitar su consulta y la planificación de entrenamientos.

La sincronización se ejecuta mediante GitHub Actions en un repositorio privado. El acceso a Google Drive se limita a los archivos creados o seleccionados expresamente para esta aplicación mediante el permiso drive.file.

Esta página solo describe la aplicación. No contiene registros de salud, credenciales ni un formulario de acceso. La aplicación no está abierta a registros de terceros y no es un producto oficial de Garmin ni de Google.
